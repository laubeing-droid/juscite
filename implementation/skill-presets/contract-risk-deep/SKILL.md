# 履约违约与履行深评（律引预装·RE-12）

在基础合同审查之上做风险专项深评：面向合同履行过程中的违约与索赔
场景，把风险拆到条款层、交易层、环境层逐层核验，只报告通过四要素
验证的风险项。本技能不替代律师判断，不自动签收任何法律结论。

| 项 | 说明 |
|---|---|
| 适用输入 | 已入案合同文本＋交易背景信息（可用则用，缺失如实标注） |
| 输出 | 完整风险报告或简要速览（双模板）＋条款层风险清单 |
| 触发 | 对话含履约风险、违约风险、合同履行、履行障碍、违约争议等语形；或以 `/skill:contract-risk-deep` 显式点名 |
| 边界 | 不核法条现行效力；无外部数据源，对手方情况一律具名待核 |

## 三层风险结构

1. **条款层**：单个条款写得有没有问题——义务不清、责任失衡、救济
   缺位。
2. **交易层**：整笔交易的风险敞口——付款与履约节奏错配、担保不足、
   验收与结算闭环缺失。
3. **环境层**：外部条件变化带来的风险——政策调整、价格波动、市场
   与主体资信变化（无数据源时具名待核，不臆测）。

## 核心概念（八项）

- **违约**：不履行或履行不符合约定；认定以约定义务与履行事实为据。
- **预期违约**：履行期届至前明确表示或以行为表明不履行。
- **根本违约**：违约致使合同目的不能实现，守约方可解除。
- **情势变更**：成立后发生的非常规变动使履行显失公平，可请求变更
  或解除，须与正常商业风险区分。
- **不可抗力**：不能预见、不能避免且不能克服的客观情况，按影响
  部分或全部免责，并及时通知举证。
- **合同解释争议**：词句歧义时按词句、条款、目的、习惯与诚信原则
  综合确定真意。
- **格式条款风险**：为重复使用而拟定、未与对方协商的条款；提供方
  未尽提示说明或有不合理免责的，对方可主张该条款不成为内容或无效。
- **效力瑕疵**：无权代理、恶意串通、违反强制性规定等导致的无效或
  可撤销形态。

## 五阶段流程

1. **信息收集与预处理**：收齐合同文本、附件、往来函件；关键材料
   缺失时列补充清单，全程低置信度标注。
2. **条款层扫描**：按七类扫描卡逐条核验（见下节）。
3. **交易层评估**：跨条款核对义务衔接、对价平衡与救济闭环。
4. **环境层评估**：外部变量与主体资信（无数据源部分具名待核）。
5. **综合评级输出**：矩阵定级、置信度标注、按双模板成文。

## 条款层七类扫描卡

逐条扫描时按下列七类对号入座，每类核对清单：

- **主体**：□资格适格 □签署权限 □权利义务主体前后一致
- **标的**：□范围明确 □质量标准可检 □权属无争议
- **价款支付**：□数额与币种明确 □节点与条件清晰 □逾期后果对称
- **履行**：□期限明确 □顺序合理 □验收与受领安排完整
- **违约责任**：□违约情形界定清楚 □责任形式与计算方式明确
  □与主给付义务匹配
- **变更解除**：□变更程序明确 □解除条件可判定 □善后结算有安排
- **争议解决**：□方式唯一确定 □管辖连接点有效 □费用负担有约定

## 条款间关系与遗漏识别

- 关系审查：定义条款与正文用语、义务条款与违约条款、解除条款与
  结算条款是否互相咬合。
- 遗漏识别：对照七类清单，整体缺席的条款类型登记为遗漏风险，不因
  "没有约定"而跳过。

## 风险四要素验证

一个风险项要进入报告，必须同时通过：

1. **事实基础**：有合同文本或已核实事实支撑，不靠想象补位。
2. **法律依据**：指向明确的请求权基础或规则（静态引用＋待核标注）。
3. **因果逻辑**：风险发生路径说得通，从条款缺陷到损失有因果链。
4. **现实可能性**：在本交易场景下确实可能发生，不是纯理论推演。

四项有其一不过，即不列入报告；如属信息缺失，转入信息不足场景处理。

## 风险筛选四规则

- **重大性**：对交易目的、主要对价或主要义务有实质影响的才留。
- **可操作性**：能给出可执行处置建议的才留；纯感慨式描述删除。
- **去重**：同一根源的多处表现合并为一条，按根源条款归属。
- **立场相关**：区分己方风险与对手方风险，报告只列己方立场下的
  风险与对策。

## 3×3 风险矩阵

发生概率（低/中/高）× 影响程度（低/中/高）→ 综合等级：

| 影响＼概率 | 低 | 中 | 高 |
|---|---|---|---|
| **高** | 中 | 高 | 高 |
| **中** | 低 | 中 | 高 |
| **低** | 低 | 低 | 中 |

判断标准——概率：条款缺陷明显且履行周期长、依赖条件多者取高；
影响：动摇交易目的或造成重大损失者取高，轻微迟延瑕疵者取低。

## 置信度与特殊标注

- 置信度三级：`[置信度：高]` 文本与依据齐备可直接判定；
  `[置信度：中]` 依据可查但事实环节有缺口；`[置信度：低]` 关键信息
  缺失或存疑，结论仅具方向性。
- 四个特殊标注：`[需补充信息]`（列明所缺材料）、`[法律争议]`
  （规则适用存在分歧）、`[地域差异]`（裁判尺度地区性强）、
  `[时效敏感]`（期限临近，须尽快行动）。
- 与全所 fail-closed 纪律同构：证据缺失一律标 UNKNOWN，不签 PASS。

## 致命错误与常见陷阱防范

| 编号 | 致命错误 | 防范 |
|---|---|---|
| F-01 | 未读全文即下结论 | 先结构概览后逐条，禁跳读 |
| F-02 | 把假设当事实 | 每项风险须过四要素验证 |
| F-03 | 编造法条或案例 | 法源锚静态引用＋待核标注 |
| F-04 | 漏看附件与空白条款 | 附件与正文同等入扫 |
| F-05 | 混淆己方与对手方风险 | 立场相关规则筛过再入报告 |
| F-06 | 以未核状态签 PASS | 守门不过具名拒，不冒 PASS |

| 编号 | 常见陷阱 | 对策 |
|---|---|---|
| T-01 | 只盯高额违约金忽略计算方式 | 责任形式与算法并查 |
| T-02 | 把商业风险误报为情势变更 | 非常规变动才可主张 |
| T-03 | 解除条件写得宽就认定可解 | 条件须可判定、程序须明确 |
| T-04 | 忽略通知与期限类程序义务 | 期限类单独登记时效敏感 |
| T-05 | 对格式条款一律认定无效 | 区分未提示说明与内容不公 |
| T-06 | 担保只看有无不看登记 | 登记与公示状态单独成列 |
| T-07 | 验收条款与付款节点脱钩 | 交易层闭环核对 |
| T-08 | 报告堆风险不给处置 | 无处置建议者筛除 |

## 六种特殊场景

1. **部分履行**：已履行部分单独评价，区分可分与不可分履行。
2. **格式合同**：逐条核对提示说明义务与异常条款，标注主张路径。
3. **涉外合同**：准据法、语言文本、仲裁地单独登记，超出本技能
   一般性提示的标注转专项。
4. **多方关联交易**：义务主体逐方对应，关联担保与资金流单独核。
5. **信息严重不足**（fail-closed）：告知缺失影响＋列补充清单＋
   标注已作假设＋全部结论低置信度＋改用条件式表述（"如果…则…"），
   绝不以占位补齐。
6. **效力存疑**：效力问题优先于风险评估，存疑期间输出条件式结论。

## 输出模板

**模板 A：完整报告**

1. 基本信息：合同名称、当事人、审查范围、信息完整度。
2. 风险总览表：等级分布（各等级数量与占比）。
3. 分级风险清单：每项含条款行号、风险描述、四要素结论、矩阵定级、
   置信度、特殊标注、处置建议、责任条款归属、时限、依据。
4. 关键建议摘要：按等级排序的行动清单。
5. 局限性说明：数据缺口、待核项与假设清单。

**模板 B：简要速览**

- 分级一句话提示（critical→low 各一条）。
- 优先行动项：签署前必须完成的事，不超过五条。

## 示例（合成合同·演示标注用法）

> 以下为合成示例，案情与条款均属虚构，仅演示输出形态。

**输入（合成《设备租赁合同》节选，已切分）**

- 行 1 第一条 租赁物：____（型号留空待补）。
- 行 2 第二条 租金：月租金拾万元整，每季度初预付。
- 行 3 第三条 违约金：承租方逾期付租的，每日按月租金的百分之五
  支付违约金。
- 行 4 第四条 争议解决：提交合同签订地法院诉讼解决。

**输出（模板 B 简要速览）**

- critical：行 1 租赁物型号空白且无补充程序约定——标的范围无法
  确定，必须补签才能用。[置信度：高]
- high：行 3 违约金日百分之五折年化显著偏高，存在被调减空间，应
  当争取下调并改设上限。[置信度：高][法律争议]
- medium：行 4 "合同签订地"未在文本中载明，建议明确到区县级。
  [置信度：中][需补充信息：签订地事实材料]
- low：行 2 季度预付对承租方偏紧，可视谈判情况争取月付。
  [置信度：高]
- 优先行动项：补齐行 1 型号并约定补充程序；下调行 3 违约金并设
  上限；行 4 载明签订地。

## 质量检查五组

- **完整性**：七类扫描卡逐类过、四要素逐项过、附件与空白条款入扫。
- **准确性**：法源引用可定位、条款行号可回溯、等级判定有依据。
- **实用性**：每项风险有处置建议、行动项可执行、优先级清晰。
- **规范性**：模板选用恰当、置信度与特殊标注逐项在位。
- **防错**：对照致命错误与陷阱表逐条自查；未核事项一律待核标注。

## 工具面

- 知识库检索：`kb.search`、`kb.read`；审查方法手册 `manual.search`。
- 法源锚：`statute.resolve` 定位、`statute.citation_gate` 标注待核。
- 外部兜底：`web.fallback_retrieve`（仅在确认自身能力缺口后使用）。
- 产出导出：`docexport.report`（风险报告）、`export.xlsx`（风险清单）。

## 失败与缺口纪律

- 守门不过：具名拒（NOT_PASS），绝不以未核状态签 PASS。
- 缺数据（如对手方履约记录无数据源接入）：具名缺口待核，绝不编造。
