# 证据目录生成（Juscite 预装）

把零散的证据材料整理成一份可以随起诉状/答辩状提交、经得起庭前会议检查的证据目录。
本技能只提供方法与格式合同，产出建议稿；定稿取舍始终由律师决定。

## 一、概述

| 维度 | 内容 |
|---|---|
| 能力 | 证据接收初筛、分类、编号、逐份摘要与证明目的撰写、按受案机关格式成表 |
| 输入 | 证据材料文件、案件事实描述、当事人信息、争议焦点 |
| 输出 | 对话内表格目录、Word 目录文书（可随卷提交）、表格清单文件 |
| 原则 | 证明目的不夸大、目录与材料一一对应、缺证如实标注 |

## 二、法律声明

本技能是整理辅助工具，输出不构成法律意见。使用时注意：

1. 目录格式以受案法院、仲裁机构的现行要求为准，提交前按其模板复核；
2. 证明目的按证据所能支持的范围客观表述，不代写夸大或推测性主张；
3. 法律依据与举证规则可能调整，以现行有效规定为准；
4. 涉商业秘密、个人隐私的证据在目录与复制件中做相应遮蔽处理；
5. 目录不能替代原件：开庭仍须按通知携带原件供核对。

## 三、分类方法（五分法，可切换）

| 分法 | 类目 |
|---|---|
| 按种类 | 书证／物证／视听资料／电子数据／证人证言／鉴定意见／勘验笔录 |
| 按证明对象 | 主体资格类、法律关系成立类、履行与违约类、损失范围类、程序事项类 |
| 按证明功能 | 直接证据／间接证据／辅助证据／反证 |
| 按来源 | 原始证据／传来证据 |
| 按证据链位置 | 基础证据／核心证据／补强证据 |

同一批证据默认按证明对象分组；用户指定其他分法时切换，并在目录备注栏注明所用分法。

## 四、操作步骤（五步）

1. **接收与初筛**：清点全部材料，剔除与本案无关的文件；按证明对象粗分组；数量多时先列材料清单再逐份处理。
2. **分类**：民事案件按证明对象归类；刑事案件按构成要件归类；行政案件按被诉行政行为的合法性要件归类；分法可切换。
3. **编号**：按"组—序"或纯顺序或按证据类型编号三选一；用分段/多级编号，给后续补证留位置。
4. **摘要与证明目的**：逐份写内容摘要与证明目的——具体、贴争点、客观不夸大、说明与待证事实的关联。
5. **排版与核对**：按受案机关格式输出目录，并与原始材料逐份交叉核对一一对应。

表格/清单生成纪律：能用一次生成就不要逐格补写；生成后抽查校验一次即定稿；
不要反复重开文件、不要输出整簿内容进对话；校验通过就交付，有警示先问清再改。

## 五、输出模板

**通用八列表**（对话内默认）：

| 序号 | 证据名称 | 证据种类 | 证据来源 | 内容摘要 | 证明目的 | 页码/份数 | 备注 |
|---|---|---|---|---|---|---|---|

**分组版式**（提交用）：每组前加组标题行"第 N 组证据：证明（一句话组目的）"；
组内证据多级编号 1.1、1.2……；法院文书类证据名称按"法院／案号／文书类型"分行排；
证明列以"证明："起头；页码列写合集内起止页，引用具体页加注，如"第 3-7 页（第 6 页）"，
多页引用用顿号分隔。

## 六、分案件类型重点

- **民事**：围绕请求权基础组织证明对象，合同、履行、损失三段各自成组；
- **刑事**：按构成要件与量刑情节分组，注意证据能力问题单独标注；
- **行政**：围绕被诉行为职权、程序、事实认定、法律适用四要件分组；
- **劳动**：劳动关系建立、工资标准、解除事由三线并进，加班与工资明细单独成组。

## 七、质量检查清单（十二项，收尾逐项过）

编号连续；名称准确；种类正确；来源可溯；证明目的不夸大；页码准确；
目录与材料一一对应；原件/复印件状态标注；格式合规；待证事实有证据支撑；
证据链完整；缺证处已标注说明。

## 八、实务经验

**筛选七问**（每份证据过一遍）：能否达到证明目的；有无更有力的替代证据；有无不利侧面；
签章是否完整；可否只交必要部分；是否最终盖章版；节选是否只在页面上选取而不在页内删改。

**不利证据四策略**：核心不利事实无法回避；主动纳入我方叙事；坦诚提交换取信任；
区分真实性争议与证明力争议。

**质证意见方法**：先按真实性、合法性、关联性逐项回应；再回应对方的证明目的；
同时指出对我方有利之处（"这份证据同时证明……"）；不在质证环节过度展开案件观点。

**参考案例提交五要**：优先指导性案例；优先管辖法院及其上级法院的同类案例；
选事实高度相似的而非仅法条相同的；附裁判要旨摘录；注意案例时效，避开已被推翻或修正的案例。

## 九、关联技能

| 方向 | 技能 | 关系 |
|---|---|---|
| 上游 | 电子数据取证审查 | 取证固化的产出作为本技能的输入证据 |
| 并行 | 事实抽取／办案时间线 | 同源材料的事实面整理 |
| 下游 | 举证质证／代理词 | 目录与证明目的是质证与代理的底稿 |

## 十、信息不足时

材料或争点信息不够时不强行出目录：先按缺口追问（缺哪类材料、争点是否确认）；
确实暂时补不齐的，先出四分法准备清单——强证据／补强证据／缺失关键证据／高风险证据——
并把缺口写进清单，不编造占位内容。

## 十一、多轮补证

后续追加的证据按既有编号规则顺延：第二组补证编 2.1、2.2……以此类推，
不重排已有编号；补证在目录备注栏注明补证轮次。

## 十二、局限性

1. 不对证据真实性做实质审查，只做形式整理；
2. 格式以受案机关现行要求为准，本技能模板不能替代其官方模板；
3. 证明力由庭审质证综合认定，目录中的证明目的仅为提交方主张；
4. 证据量大或法律关系复杂时，编排需人工调整；
5. 电子证据注意固化与提交规范，本技能不替代公证/区块链固证流程。
