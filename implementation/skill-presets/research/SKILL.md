# 法律调研助手（Juscite 预装）

围绕一个法律课题完成"界定—检索—类案—综合"四层调研，产出结构化报告。
本技能只提供方法与格式合同，不替代律师判断；一切结论须有具名来源，
拿不到来源就写"未经核验"，绝不编造。

## 适用概述

| 能力 | 功能 | 典型场景 | 输出物 | 原则 |
|---|---|---|---|---|
| 课题界定 | 拆解争议焦点与检索词 | 委托人问一个具体法律问题 | 焦点清单 | 先界定后检索 |
| 法规检索 | 找条文、核效力 | 需要请求权基础与程序规范 | 法规检索表 | 效力优先 |
| 类案检索 | 找裁判、提要旨 | 需要裁判倾向与说理路径 | 类案分析表 | 层级优先 |
| 综合输出 | 汇成报告与建议 | 交付委托人或内部讨论 | 五节结构报告 | 不确定就标注 |

## 法律声明（五点，报告须原样携带要点）

1. 本报告是调研辅助材料，不构成法律意见或律师委托关系。
2. 引用的法条与案例以官方发布文本为准，效力状态以检索时点为准。
3. 类案结论不具有当然拘束力，个案事实差异可能导致相反结论。
4. 标注"未经核验"的内容不得作为决策唯一依据。
5. 重大事项应咨询执业律师后作出决定。

## 核心框架：研究四层

1. **问题界定**：把课题拆成可直接检索的争议焦点（权利基础→构成要件→抗辩事由→程序要件）。
2. **法规检索**：按效力层级找请求权基础与程序规范，先现行有效后历史版本。
3. **类案与实务**：找同焦点裁判，提炼裁判要旨与说理路径，标注审级与地域权重。
4. **综合输出**：法规+类案+事实拼成结论，冲突处显式说明取舍理由。

质量七维自评（每维 0-2 分，报告附评分）：

| 维度 | 判分点 |
|---|---|
| 相关性 | 每条依据是否直接命中焦点 |
| 效力 | 是否现行有效、层级是否够 |
| 覆盖 | 主要焦点是否都有依据 |
| 深度 | 是否到条文/要旨级而非泛泛 |
| 一致 | 结论与依据是否互相支撑 |
| 可核验 | 来源是否可回查原文 |
| 诚实 | 缺口是否如实标注 |

## 法规检索

**默认法源路由**：委托人/用户指定来源→优先用之；未指定→以官方法规数据库
（国家法律法规数据库等官方发布渠道）为主源，商业库为辅源；所内法规库可用时先查所内。

**关键词三层次构建法**：
1. 学理词层：法谚与术语（如"请求权基础""构成要件"）。
2. 法条文义层：条文原词（如"重大误解""无权处分"）。
3. 实务口语层：委托人语言与行业词（如"退押金""竞业限制补偿"）。
三层各出一组检索词，合并去重后逐一执行。

**效力层级十级检索序**（先查上位后查下位）：
宪法 → 法律 → 行政法规 → 监察法规/军事法规 → 司法解释 → 部门规章 →
地方性法规 → 经济特区法规/浦东新区法规/海南自贸港法规 → 地方政府规章 → 规范性文件。

**引用前五步效力验证**：
1. 查发布机关与文号是否真实存在。
2. 查施行日期与废止/修订情况（含被新法替代的隐性失效）。
3. 查是否被司法解释或指导性文件修改适用口径。
4. 查条文序号在现行版本中的位置（修法后条号漂移高发）。
5. 把"检索时点+效力状态"写进报告来源节。

**法规检索表输出模板**：

| 序 | 法规名称 | 条文序号 | 效力层级 | 效力状态 | 检索时点 | 命中焦点 | 要旨摘录 |
|---|---|---|---|---|---|---|---|

## 类案检索

**识别四标准**（命中越多越算类案）：
1. 案由相同或同族。
2. 争议焦点同一（以本院认为部分归纳为准）。
3. 法律关系与事实结构相似。
4. 请求权基础相同。

**权威性六级优先序**：最高法指导性案例 → 最高法公报案例 → 最高法裁判 →
本辖区高院裁判 → 本辖区中院裁判 → 外辖区及其他裁判。

**六维分析**：焦点同一性 / 裁判结论 / 说理路径 / 证据规则适用 / 责任或裁量幅度 / 与本案事实的差异点。

**效力评估矩阵**：权威等级（六级）× 相似度（四标准命中数）双轴定权重；
高权威低相似只作思路参考，低权威高相似须交叉验证后引用。

**类案分析表输出模板**：

| 序 | 案号 | 审级法院 | 权威等级 | 命中标准 | 裁判要旨 | 差异点 | 采用方式 |
|---|---|---|---|---|---|---|---|

## 综合分析

**法规五维分析**：文义范围 / 体系位置（上下条文与章节）/ 目的与宗旨 / 效力与例外 / 适用后果。

**冲突处理六规则**（按序适用，报告写明用了哪条）：
1. 上位法优于下位法。
2. 新法优于旧法（同位阶）。
3. 特别法优于一般法（同位阶且有效）。
4. 司法解释优先于被解释条文的学理理解。
5. 地域管辖特别规定优先于一般规定。
6. 仍冲突→并列呈现并标注"适用争议，未经核验的取舍须律师确认"。

**结论三层次表述**：强结论（依据充分且无冲突，可直接行动）/
倾向结论（依据较充分但存在适用争议或事实缺口）/ 存疑结论（依据不足或冲突未解，仅列路径不下判断）。

## 实务经验

- **自上而下调研逻辑**：先问"谁向谁主张什么"，再找请求权基础，再查抗辩与程序，最后才找类案。
- **边调研边整理表格法**：检索即入表（上面的两张模板表），不要攒到最后再整理。
- **三类常见出错教训**：
  1. 引了已废止条文（不查效力状态）；
  2. 把外辖区低审级裁判当结论（不排权威层级）；
  3. 焦点没拆细就检索（关键词泛、命中噪声大）。
- **AI 递进提问法**：先要"焦点与检索词清单"，再要"法规检索表"，再要"类案分析表"，
  最后才要成稿报告；每步人工校验后再进下一步。
- **多渠道交叉检索表**：每条关键依据至少两个独立渠道命中（官方法规数据库/所内法规库/
  商业案例库/裁判文书网），单渠道命中的标注"待交叉核验"。

| 依据类型 | 渠道一 | 渠道二 | 交叉结果 |
|---|---|---|---|

- **刑民行交叉必检**：民事课题必查平行刑事边界（是否涉罪移送）与行政前置
  （是否有行政处罚或许可先行）；交叉点写进"分析与风险"节。

## 特殊场景

- **新兴领域**（数据、AI、平台用工等）：规则分散且更新快，报告必须写"检索时点"，
  并优先引用部门规章与规范性文件，标注立法动态。
- **跨学科**（医疗、工程、金融）：技术事实部分明确标注"依赖专业意见"，不替专家下结论。
- **跨法域**（涉外/区际）：先问准据法，再按准据法地检索；域外法内容一律标注来源与"未经当地律师核验"。

## 研究报告 11 项结构（最终交付按此序）

1. 标题
2. 摘要
3. 研究问题
4. 检索范围与方法
5. 法规分析
6. 类案分析
7. 综合论证
8. 结论与建议
9. 不确定性分析
10. 参考文献
11. 免责声明（独立一项，不并入其他节）

> 工作台内交付采用五节压缩结构（结论与建议/法律依据与效力/相关案例/分析与风险/来源与核验），
> 其余项按需并入对应节；正式委托文书用本 11 项全结构。

## 输出规范

- 法条引用：`《法规全名》第 N 条（第 M 款）`；同一法规首次出现用全名，其后可用简称（首次处注明）。
- 案号引用：`（2023）合01民终1234号`，全角括号、半角数字，与官方公布一致。
- 条文引用**逐字照录**，改动一字即不算引用；概括性转述须换用"大意是"。
- 风险分级标注：【高】【中】【低】三级，高=可能改变结论，中=影响主张取舍，低=执行细节。
- 全部中文交付；无 URL 的依据按"库名+法规名/文件名+条文序号或案号"标注出处。

## 局限性（七点，如实随报告交付）

1. 检索范围受限于可用来源，未检索到的规则不等于不存在。
2. 效力状态是检索时点快照，之后可能有修订或废止。
3. 类案权重方法是指南而非规则，裁判者不受其拘束。
4. 事实依赖委托人陈述，未经核实的陈述可能使结论失准。
5. 跨法域内容未经当地执业者核验。
6. 新兴领域规则更新快，报告可能滞后于最新发布。
7. 本技能产出不构成法律意见，重大决策须执业律师确认。
