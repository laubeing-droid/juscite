# 证据材料整理（Juscite 预装）

把起诉状、证据 PDF、照片等散件整理成一份条目清楚、页序对齐的证据清单，必要时合成
带连续页码的合集文件。本技能只提供方法合同，产出为建议稿，定稿由律师确认。

## 一、四阶段工作流

1. **收料**：按第二节边界逐份读取材料，登记名称、来源、页数；
2. **清单化**：逐份写摘要与证明指向，命名从文件名里的日期、案号取线索；
3. **生成**：按第三节写作规范产出清单文书；
4. **合集**（可选）：按清单顺序合成合集并加连续页码，清单页码列与合集页序对齐。

## 二、收料边界

- 起诉状、案情类 docx：读正文文字与表格，不猜未写明的内容；
- 证据 PDF：提取文字与页数，按页登记；扫描件无文字层时标注"无文字层，按页数计"；
- 照片 JPG/PNG：只读文件属性与外观尺寸，**不做 OCR**；照片内容以起诉状等文书的
  文字引用为准，不凭图像自行认读；
- 旧格式 .doc 等：先转档为可读格式再收，转不了的单列"待转档"；
- 文件名中的日期、案号作为证据名称与排序线索，仅是线索不是结论。

## 三、写作规范（六条）

1. 证据推导有边界：收条只证"收款"，不证"款项未转交他人"；证明内容不超出证据本身；
2. 避免指代不明："其""该方"改成明确名词；
3. 引用原文时句末标页码，如"……（见原文第 4 页）"；
4. 判决类证据写"判决认定 X，印证 Y"，不只复述判决；
5. 工作提示写在对话里，不写进文书；
6. 落款按文书类型匹配：起诉状＝具状人，证据清单＝提交人，申请书＝申请人。

## 四、清单版式

- 平铺式：编号／证据名称／证明内容／页码 四列；
- 分组式：组标题行整行合并，写"第 N 组证据：证明（组目的）"；组内多级编号 1.1、1.2，
  补证按 2.n 顺延；
- 法院文书类证据名称按"法院／案号／文书类型"分行排；
- 页码列写合集内起止页，引用具体页加注（第 X 页），多页引用顿号分隔。

## 五、合集规则

- 合集按清单编号顺序逐件编排，页码从 1 连续编号；
- 清单页码列与合集实际页序必须一致，不一致时以合集实测页序回改清单；
- 横向内容等比缩放排入纵向页面，不裁切、不改变原始朝向；
- 无法识别的文件类型跳过并在清单备注，不占页码。

## 六、局限与确认

照片不做 OCR，内容引用依赖文书文字；合集页序在材料增删后须重新对齐；
提交前的原件核对与份数确认由律师完成。
